# Shell Script for User Management and Backup in Linux

## 📌 Project Overview
This project is a **Linux shell scripting solution** designed to automate **user management** and **directory backup** tasks.  
It helps system administrators efficiently manage users, groups, and backups using a single Bash script.

The project focuses on practical Linux administration skills such as user handling, permissions, backup automation, and version control using Git and GitHub.


## 🛠 Tools & Technologies Used
- Linux Operating System (Ubuntu, Fedora, etc.)
- Bash Shell
- Git & GitHub
- Text Editor (Vim, Nano, or VS Code)

![jenkins](images/add_user.png)

## 📂 Project Description
The shell script performs the following operations:
- Add, delete, and modify Linux user accounts
- Create and manage user groups
- Take compressed backups of specified directories
- Provide a user-friendly command-line menu with clear options

This project strengthens understanding of **Linux commands, shell scripting, automation, and system administration concepts**.


## ✅ Functional Requirements
- User account management (add, delete, modify)
- Group creation and management
- Directory backup with compression
- Interactive command-line interface with usage instructions


## ⚙️ Non-Functional Requirements
- **Performance:** Executes tasks efficiently
- **Security:** Requires appropriate permissions to prevent unauthorized access
- **Portability:** Works across multiple Linux distributions


## 🎯 Objective
To automate Linux user management and directory backup processes using shell scripting.
